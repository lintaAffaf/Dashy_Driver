# Dashy Driver

Dashy Driver is a 2D delivery game developed in Unity using C#.
Players control a van to pick up packages and deliver them to customers, using boosters to increase speed and avoid obstacles.

## Features

- 2D top-down delivery gameplay  
- Package pickup and delivery system  
- Speed boosters for enhanced gameplay  
- Smooth movement and simple controls  
- Developed with Unity fundamentals and C#
